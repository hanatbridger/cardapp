# CardPulse marketing site

Next.js App Router, plain CSS (custom properties + native nesting).
Ten hand-written pages; no CMS, no runtime API calls.

```
npm run dev     # localhost:3000
npm run build
```

Deployed as its own Vercel project with root directory `website/`.
Tokens mirror `../src/theme/tokens.ts` — change colours there first,
then here.
